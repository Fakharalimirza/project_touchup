# **App Name**: TouchUp Hub

## Core Features:

- Homepage Hero Section: Display a hero section with a background image/video and prominent 'Book Now' or 'Get a Quote' call-to-action.
- Services Overview: Present an overview of services offered (Cleaning, AC Maintenance, Plumbing, etc.) with icons and short descriptions.
- Testimonials: Include a testimonials section to build trust and credibility.
- Booking/Quote Form: Implement a booking/quote form with fields for name, contact details, service required, date/time, address, and special instructions. Submissions sent to admin email.
- Service Detail Pages: Create individual pages detailing each service offered, including descriptions, and optional link to modal popups.
- Contact Us Page: Include a contact form with fields mirroring the booking form, along with Google Maps location, WhatsApp direct link, phone, email, and office hours.
- AI-Powered Blog Title Generator: Implement a basic blog that generates titles from provided keywords and constraints. The AI tool assists the user in providing interesting names and tips (e.g. 'AC maintenance tips') and assists the blog writer in determining whether each generated title fits their prompt constraints, so that a more streamlined user experience can be achieved.  

## Style Guidelines:

- Primary color: Deep blue (#293B8F) for trustworthiness and professionalism, drawing inspiration from the brand's focus on dependable home maintenance services.
- Background color: Light gray (#F0F2F5), a very lightly saturated version of the primary color, for a clean and modern backdrop.
- Accent color: Light blue (#64B5F6), analogous to the primary blue but lighter, for highlighting key actions and information.
- Body and headline font: 'Inter' sans-serif for a modern, clean, and easily readable appearance across all devices. Note: currently only Google Fonts are supported.
- Mobile-first responsive design ensuring optimal viewing experience across all devices.
- Use a consistent set of minimalist icons to represent services and key features.
- Subtle transitions and animations to enhance user experience, such as hover effects on buttons and smooth scrolling.
